# Привет

Инженер ИТ-инфраструктуры / DevOps: сети, серверы, виртуализация, мониторинг. Десять лет держу в работе распределённую инфраструктуру — от площадок на спутниковых каналах до корпоративных сервисов.

Здесь пет-проекты, которые делаю по ходу: не туториалы, а работающие системы с документацией и разобранными отказами.


## Проекты

**[docker-monitoring-stack](https://github.com/osltbs/docker-monitoring-stack)** — Prometheus, Grafana, Loki, cadvisor и promtail в Docker Compose. Метрики хоста и контейнеров, системные логи и логи контейнеров, 16 правил оповещения с доставкой в Telegram. Дашборды, источники данных и алерты — файлами в репозитории, а не кликами в интерфейсе.


## Чем работаю

**Сети** — MikroTik RouterOS, Cisco Catalyst, VLAN, VPN, QoS, балансировка каналов, VSAT

**Серверы** — Windows Server, Active Directory, Hyper-V, Ubuntu, Debian, LXC

**Linux** — nginx, BIND9, systemd, bash, nftables, TLS

**Мониторинг** — Prometheus, Grafana, Loki, Zabbix, SNMP, IPMI

**Диагностика** — tcpdump, Wireshark, разбор трафика и дампов
